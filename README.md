# Executando Programas JavaScript (Exercícios 1-15) no VS Code

Este guia fornece os códigos JavaScript para os exercícios listados e assume que você já tem o VS Code instalado, o Node.js instalado e a biblioteca `prompt-sync` instalada (caso contrário, siga as instruções abaixo para configurá-los).

## Pré-requisitos:

* **VS Code (Visual Studio Code):** Um editor de código gratuito. Você pode baixá-lo em [https://code.visualstudio.com/](https://code.visualstudio.com/).
* **Node.js:** Um ambiente de execução JavaScript fora do navegador. Você pode baixá-lo em [https://nodejs.org/](https://nodejs.org/).
* **`prompt-sync`:** Uma biblioteca para receber entrada do usuário no terminal. Para instalá-la, abra o terminal no VS Code (Terminal > Novo Terminal) e execute o comando:
    ```bash
    npm install prompt-sync
    ```

## Como Executar os Exercícios:

Para cada exercício, siga estes passos:

1.  **Abra o VS Code.**
2.  **Crie um novo arquivo:** Vá em "Arquivo" (File) > "Novo Arquivo" (New File) ou pressione `Ctrl+N` (Windows/Linux) ou `Cmd+N` (macOS).
3.  **Cole o código JavaScript** do exercício correspondente (listado abaixo) no novo arquivo.
4.  **Salve o arquivo:** Vá em "Arquivo" (File) > "Salvar" (Save) ou pressione `Ctrl+S`. Escolha um local para salvar o arquivo e dê um nome a ele com a extensão `.js` (por exemplo, `exercicio1.js`).
5.  **Abra o terminal no VS Code:** Vá em "Terminal" > "Novo Terminal".
6.  **Navegue até a pasta** onde você salvou o arquivo usando o comando `cd` (change directory). Por exemplo, se você salvou na pasta "exercicios\_js" na sua área de trabalho:
    ```bash
    cd Desktop/exercicios_js
    ```
7.  **Execute o arquivo JavaScript:** Use o comando `node nome_do_arquivo.js` (substitua `nome_do_arquivo.js` pelo nome real do arquivo). Por exemplo:
    ```bash
    node exercicio1.js
    ```
8.  **Pressione Enter.** A saída do programa será exibida no terminal. Para exercícios que pedem entrada do usuário, o terminal irá esperar você digitar algo e pressionar Enter.
